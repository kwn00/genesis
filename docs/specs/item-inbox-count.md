# 아이템 개수 표시

예시 인박스에 현재 아이템 개수를 보여 주는 리허설 기능. 바퀴가 GitHub에서 끝까지 도는지 확인한다.

## 누가, 무엇을, 왜

- 누가: 이 템플릿으로 바퀴를 돌려 보려는 팀
- 무엇을: `/example` 목록 위에서 아이템이 몇 개인지 본다
- 왜: `bdd-draft` PR → lock → `implement` PR → 머지가 라벨·CI·브랜치 보호와 함께 실제로 동작하는지 리허설하려고

## 화면에서 보이는 성공 한 줄

`/example`에 "아이템 N개"가 보이고, 하나 추가하면 N이 1 늘어난다.

## 통과 조건

- Given `/example` 페이지에 접속한다
- Then "아이템 N개" 형식의 개수가 보인다
- When 제목을 입력하고 추가한다
- Then 개수가 N+1로 바뀐다

## 설계 메모

- 화면/라우트: `/example`. 목록 위에 `아이템 N개` 텍스트 한 줄
- API: 변경 없음. `/api/example/items` 그대로
- 데이터: 개수 = 현재 목록 길이. 서버 상태 추가 없음
- 코드 위치: `src/app/example/item-inbox.tsx`

## 이번엔 안 하는 것

- 개수 전용 API, 조건별 개수, 애니메이션

## 더미 데이터 가정

- 시드: `Alpha`, `Beta` (기존 그대로)
- 서버 메모리. 프로세스 재시작 시 시드로 돌아간다
- 사내 데이터·개인정보 없음
